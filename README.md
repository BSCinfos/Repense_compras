# Compre com Consciência

Sistema de e-commerce educativo feito com **HTML, CSS e JavaScript puro**, focado em consumo consciente.

## Novas Funcionalidades Implementadas

- **Detalhes do Produto ao Clicar**: Ao clicar em qualquer item da vitrine, abre-se uma janela exibindo a imagem completa do produto, preço médio de mercado, descrição detalhada, opção **Comprar depois** (lista de favoritos/reflexão) e **Adicionar ao carrinho**.
- **Cadastro Sob Demanda**: A interface de adição de novos produtos inicia oculta e é exibida apenas ao clicar no botão **Adicionar produto** no menu superior.
- **Filtro Completo**: Permite filtrar os produtos por **nome/termo**, **faixa de valor (mínimo e máximo)** e **20 categorias** baseadas na Amazon e Mercado Livre.
- **Catálogo com 60 Produtos**: 3 produtos pré-cadastrados em cada uma das 20 categorias, com valores baseados na média de mercado e descrições detalhadas.
- **Imagens Inteiras e Compactas**: Exibição com `object-fit: contain` em tamanho ajustado para visualização completa sem cortes.

## Como executar

1. Extraia os arquivos da pasta `compre_com_consciencia`.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno.
